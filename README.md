
Проверка версии Node.JS  
```
node -v
```

1. Скачать и установить node.js (один раз)
2. Открыть проект в VS code
3. Открыть терминал

после установки (обновления node.JS), в терминале пишем 'cd..'
C:\Users\Admin\Desktop\(название проекта)> (чтобы удалилось название проекта)
```
cd..
```

затем пишем
```
npm create vite
```

дальше окно: 'Ok to proceed?' - пишем 'y'

Project name: пишем название вашего проекта(как на верху) 

Package name: » (оставляем название как есть)

выбираем Vanilla -> Typescript

ДАЛЕЕ:

Если все правильно, то выйдет окно:
Done. Now run:

  cd (название проекта БЕЗ заглавных букв) privatejavascript
    C:\Users\Admin\Desktop> cd privatejavascript
  
  npm install
  npm run dev

делаем глобальную ссылку:
1. после того как  запушили проект (сделали public, а не private) идём в репозиторий на гитхабе ->settings->pages->source (выбираем GitHub Actions)

2. страница обновится и выбрать 'create your own' сюда вставляем скопировнный текст, проверяем если вверху написано 'main' (вверху), то мы в скопированном тексте так и оставляем 'main', если написано 'master', то в скопированном тексте пишем 'master' 

3. в этой же верхней строке пишем 'main.yml' (без кавычек, через точку)

4. нажимаем на кнопку 'commit changes'
5. Переходим обратно в проект и через 'Settings' добавляем ссылку


6. Создать файл vite.config.ts

в нём пишем:
export default {
    base:'/  имя проекта  /'
}
